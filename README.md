# رِواق المتون | Riwayq Al-Mutun

منصة عربية مجانية ومفتوحة المصدر تساعد طالب العلم على تنظيم حفظ المتون ومراجعتها، مع دعم العمل دون اتصال بالإنترنت (PWA).

## المزايا في النسخة الأولى
- واجهة عربية كاملة باتجاه RTL.
- مكتبة متون قابلة للبحث والتصفية حسب العلم.
- عرض المقاطع مع إخفاء النص لاستظهار الحفظ.
- إظهار الملاحظات والشروح المضافة للمقطع.
- تسجيل حالة كل مقطع: جديد / للمراجعة / متقن.
- حفظ التقدم محلياً في المتصفح.
- Service Worker لتخزين ملفات التطبيق والعمل دون اتصال بعد أول تحميل ناجح.
- قابل للتثبيت كتطبيق على الأجهزة والمتصفحات الداعمة.

## تشغيل المشروع محلياً

> يجب تشغيله عبر خادم محلي؛ فتح `index.html` مباشرة عبر `file://` لا يفعّل Service Worker.

### باستخدام Python
```bash
python3 -m http.server 8000
```
ثم افتح: http://localhost:8000

### باستخدام VS Code
يمكن استعمال إضافة Live Server ثم فتح عنوان localhost الذي توفره.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً باسم `riwaq-almutun`.
2. ارفع محتويات هذا المجلد إلى الفرع الرئيسي.
3. من Settings ثم Pages اختر النشر من الفرع الرئيسي `/ (root)`.
4. افتح رابط الموقع مرة واحدة مع اتصال بالإنترنت لتخزين ملفات التطبيق.
5. بعد ذلك يمكن فتحه دون اتصال من نفس الجهاز والمتصفح.

## إضافة متن أو مقاطع جديدة
حرّر ملف `mutun.json` الموجود في جذر المشروع. الملف عبارة عن مصفوفة من المتون، لذلك أضف كل متن كعنصر داخل المصفوفة:

```json
[
  {
  "id": "unique-matn-id",
  "title": "اسم المتن",
  "subject": "العلم",
  "description": "وصف مختصر",
  "items": [
    {
      "id": "unique-item-id",
      "reference": "الباب أو رقم البيت",
      "text": "النص المضبوط بعد مراجعته",
      "note": "شرح مختصر موثق أو ملاحظة"
    }
  ]
  }
]
```

يجب أن يكون `id` فريداً لكل متن ولكل مقطع داخله. افحص صحة البيانات بالأمر `node Validate.mjs`. بعد تحديث البيانات، ارفع إصدار ذاكرة التخزين في `sw.js` (غيّر `riwayq-v8` إلى إصدار جديد) حتى تُحمّل الأجهزة النسخة المحدّثة.

## تنبيه علمي
هذه نسخة تقنية أولية وليست تحقيقاً علمياً للمتون. البطاقات التي تحمل وصفاً بأنها مكانية ليست نصوصاً أصلية. لا تنشر متنًا أو شرحاً قبل مقابلة النص على طبعة موثوقة، وتوثيق المصدر والطبعة والجزء/الصفحة عند الحاجة، ومراجعة أهل الاختصاص.

## فحص البيانات تلقائياً
يوجد سير عمل GitHub Actions في `.github/workflows/validate.yml` يفحص `mutun.json` عند كل `push` أو `pull request`.

## الخصوصية
التقدم محفوظ محلياً في `localStorage` على الجهاز والمتصفح الحالي. لا يوجد حساب مستخدم أو إرسال بيانات إلى خادم في هذه النسخة. مسح بيانات المتصفح قد يؤدي إلى فقدان التقدم.
