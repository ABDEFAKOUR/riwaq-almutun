# مكتبة شروح المتون بالفيديو

ضع ملفات الشرح بصيغة MP4 داخل هذا المجلد، ثم أضف بياناتها إلى `../videos.json`.

مثال:
```json
[
  {
    "id": "unique-video-id",
    "title": "عنوان الدرس",
    "matn": "اسم المتن",
    "teacher": "اسم الشيخ",
    "source": "رابط أو مرجع موثوق",
    "src": "videos/lesson.mp4"
  }
]
```

لا تضف درساً أو نسبةً لشيخ دون التحقق من الملف والمصدر. ملفات الفيديو الكبيرة قد لا تناسب التخزين المحلي في بعض الأجهزة.
